## 📋 3 Login Methods

### Method 1: Email/Password
1. Go to `/login`
2. Click "Email Login" tab
3. Enter email and password
4. Tenant auto-detected
5. Click "Sign In"

### Method 2: Quick Login
1. Go to `/login`
2. Click "Quick Login" tab
3. Select Tenant dropdown
4. Select User dropdown
5. Click "Sign In"

### Method 3: Register
1. Go to `/login`
2. Click "Register" tab
3. Enter tenant name
4. Enter email and password
5. Click "Register Tenant"
6. Login with new credentials

## 🎯 Common Tasks

### Change Theme
1. Click theme icon (top right)
2. Select Light/Dark/System
3. Done! (Auto-saves)

### Toggle Sidebar
**Desktop**: Click toggle button
**Mobile**: Click hamburger menu, then close or click overlay

### Logout
1. Click user avatar (top right)
2. Click "Logout"
3. Redirected to login page

### Apply for Leave
1. Go to Leave Management
2. Click "New Request"
3. Fill dates and reason
4. Submit
5. Manager approves

### View Payslip
1. Go to Payroll
2. Click month
3. View components
4. Check deductions
5. View net salary

### Submit Expense
1. Go to Travel & Expenses
2. Click "New Claim"
3. Select category
4. Enter amount
5. Add description
6. Submit

## ❓ FAQ

**Q: How do I login?**
A: Use any demo credential with email/password method.

**Q: Can I switch themes?**
A: Yes, click theme icon (sun/moon) in top bar.

**Q: How do I collapse sidebar?**
A: Click toggle on desktop or hamburger on mobile.

**Q: What data persists?**
A: Session persists, data resets on refresh (mock data).

**Q: How many users can login?**
A: 5 demo accounts (all roles) + unlimited new registrations.

**Q: Is it password protected?**
A: Yes, use provided credentials or register new tenant.

**Q: Can I access on mobile?**
A: Yes, fully responsive design.

**Q: How do I reset my session?**
A: Refresh page or logout and login again.

**Q: Which browser to use?**
A: Any modern browser (Chrome, Firefox, Safari, Edge).

**Q: Is there a backend?**
A: No, uses mock data. Perfect for frontend testing.
